An unofficial Windows build of [HushSnap](https://github.com/tcita/HushSnap), originally created by [tcita](https://github.com/tcita).

This fork is based on **HushSnap v1.6.2** and intentionally retains its **Auto OCR After Capture** feature. Auto OCR is an existing upstream feature and was not introduced by this fork.

## What's different?

This build focuses on a simpler screenshot-saving workflow:

- Screenshots are saved to the Windows **Screenshots** folder by default.
- **Settings ??General ??Image Save Location** lets you choose a custom folder.
- Thumbnail and pinned-image saving use the same configured location.
- **Use Default** restores the Windows Screenshots folder.
- Includes a conventional Windows `.exe` installer.
- Supports English, Simplified Chinese, Traditional Chinese, and Japanese UI.

## Download

Download the latest Windows installer from [Releases](../../releases).

The installer is currently unsigned, so Windows SmartScreen may display an **Unknown publisher** warning.
